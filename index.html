Efficient Adaptation of Dense Object Descriptors with application to CAD-to-real Robotic Grasping

Anonymous Authors

IEEE Robotics and Automation Letters

Abstract

Dense visual descriptors have become a useful object-centric representation for robotic manipulation, as they allow object points, parts, and targets to be matched across different viewpoints and object poses, in both empty and cluttered scenes. However, learning accurate descriptors typically depends on dense correspondence supervision, which is expensive to obtain from real data, while models trained only in simulation often suffer from a sim-to-real gap. We propose an improved Dense Object Nets training pipeline designed to leverage synthetic pretraining and support real-world deployment with minimal annotation effort. The pipeline combines a contrastive pixel- and instance-level loss, triplet-based sample construction, self-matching on real images, and domain-adversarial alignment. Starting from CAD-generated synthetic data, the model is fine-tuned using only a small set of real images, without requiring real object-pose supervision. Experiments on YCB-V and T-LESS evaluate the proposed design and compare the resulting descriptors against recent pretrained visual encoders. Results show that, while large general-purpose encoders are strong for coarse correspondence on common objects, compact specialized DONs remain competitive for accurate matching and less common object domains. Real-world bin-picking experiments further show that the proposed self-matching and domain-adversarial based adaptation improves CAD-to-real keypoint localization and grasp execution compared with synthetic-only training
